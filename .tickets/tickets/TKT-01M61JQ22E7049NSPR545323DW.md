## Description

A run of mode `ask`, pinned to the change's exact base and head read fresh from the forge, with the scope `change` or `since_review` and the range rules of a summary (section 6.4). Its first message is a canned prompt or the person's question, and the person can follow up any number of times on the same session. An ended session is resumed with `Spec.Resume`, so a conversation carries on after a restart. When the change's head moves, the run is marked stale with both heads. Summary runs (mode `summary`) are read as conversations whose prompt is `explain`, in place.

The session has the reviewer lockdown: Read, Grep, Glob, no shell, no web, no extensions, none of the person's MCP servers, and no drafts server. The context server comes in its own ticket.

Design: docs/plan.md section 6.11, D68.

## Acceptance criteria

- [ ] An ask run pins the fresh base and head, with scope change or since_review
- [ ] The person can follow up on the same session, and after a restart it resumes
- [ ] A moved head marks the conversation stale and names both heads
- [ ] Summary runs read as explain conversations, unchanged on disk
- [ ] The session's tools are Read, Grep, Glob and the context server only, and a test proves it
